# Retekess Monitor + All Off — experimental Flipper Zero app

Built for Momentum mntm-012 / FAP API 87.1. It monitors empirically reproducible T130U streams on EU CH18 and CH19 and the separate CHS control band. It also replays one measured CH19 All Off frame when OK is held in CH19 mode. This exact frame shut down the user's paired T131U in two controlled tests; the app cannot synthesize arbitrary commands. It is not a complete packet decoder.

Install `retekess_rx_monitor.fap` under `/ext/apps/Sub-GHz/` or build and launch with `ufbt launch` from this source directory. Left/right cycles CH18 (863.475 MHz receiver center), CH19 (863.975 MHz) and CHS (864.475 MHz). Back exits. The screen backlight stays on while running. Periodic RTC summaries go to `/ext/retekess_probe/monitor_session.csv` on Flipper SD, overwritten on the next run. In the CSV, receiver_mode 20 means CHS; `tx_sent` counts completed All Off transmissions.

To send All Off to the paired T131U on CH19, turn off T130U, leave T131U on CH19, select CH19 mode in the app, and hold OK. The display reports `AllOff TX: SENT` when the bounded transmission completes. The app uses a 1984-bit frame captured during a real All Off action, replayed 64 times at approximately 250 kbaud on 863.975 MHz with the CC1101 PA setting corresponding to about −10 dBm. It enforces a ten-second interval between sends. Transmission is limited to this tested command and channel. The Flipper's regional TX check must allow the frequency.

`Marker: YES` means an empirical 32-bit alignment sequence was found recently. On CH18/CH19, `Field 529` is a 16-bit sample relative to the marker and measured 1984-bit period. `AllOff cand` counts exact `0x7777` fields on CH19 only, because that is the channel on which a receiver shutdown was observed. On the CHS band, fields `0x1110`, `0x1112`, `0x1113` were observed during successful receiver transitions to CH16, CH18 and CH19 respectively; the app displays these as candidate targets. It does not extrapolate to unmeasured channels. Bit errors can produce other values.

The alignment sequences are `0x9B1BA4A5` (CH18), `0x9B1BA525` (CH19) and `0x9B1BA5A6` (CHS). They are useful repeatable markers, not proven packet sync words. The 1984-bit spacing was observed directly. The experimental receiver uses a 249.939 kbaud GFSK hypothesis, ~127 kHz deviation setting, ~542 kHz RX bandwidth and asynchronous GDO0 output sampled every 500 ns. These settings recover candidate bits; they do not establish the T130U transmitter's exact radio settings, frame layout, CRC or group ID.

The app listens to one frequency at a time. It cannot watch an ordinary channel and CHS simultaneously. CHS transmission remains experimental and is not included: replay tests on 864.475 MHz did not move T131U. Changing only the observed `0x0000` to `0x7777` in a normal frame also failed to shut it down, so the app uses the complete working capture. For raw measurements and limitations, see `RESEARCH_LOG.md` and `captures/` in the companion deliverables.
